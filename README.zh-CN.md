# 伪距差分定位 C++ 程序

[English README](README.md)

这是本科毕业设计中的伪距差分定位程序，使用 C++ 实现基于 RINEX 文件的
GPS 伪距差分定位处理流程。

## 项目内容

- `solution1.cpp`：程序入口和伪距差分定位主流程；
- `fileread.cpp` / `fileread.h`：RINEX 2 导航文件、观测文件读取，
  观测历元匹配及差分数据准备；
- `solution1.vcxproj`：Visual Studio 控制台应用项目文件；
- `data/sample/`：用于测试的两组 RINEX 示例数据；
- `LICENSE`：MIT 开源许可证。

程序首先处理基准站观测数据，根据基准站已知的 ECEF 坐标计算伪距改正数，
然后读取流动站观测数据，匹配观测历元并应用差分改正，最后计算流动站坐标。

> `calculate_class_version` 是独立的类版单点定位实现，不是本差分定位程序
> 的运行依赖。本仓库当前只包含伪距差分定位核心程序。

## 示例数据

`data/sample/` 中包含两组可以分别使用的同日 RINEX 数据。每组数据应当
单独使用，不要混用不同日期的文件。

### 示例一：2019-03-20

| 文件 | 作用 | 测站 |
| --- | --- | --- |
| `brdc0790.19n` | GPS 广播星历文件 | - |
| `hksl0790.19o` | 基准站观测文件 | HKSL |
| `hkws0790.19o` | 流动站观测文件 | HKWS |

HKSL 观测文件头中的近似 ECEF 坐标为：

```text
-2393382.4160 5393861.1750 2412592.4110
```

### 示例二：2018-03-05

| 文件 | 作用 | 测站 |
| --- | --- | --- |
| `brdc0640.18n` | GPS 广播星历文件 | - |
| `bor10640.18o` | 基准站观测文件 | BOR1 |
| `wroc0640.18o` | 流动站观测文件 | WROC |

BOR1 观测文件头中的近似 ECEF 坐标为：

```text
3738358.5958 1148173.5785 5021815.7483
```

正式进行精度评定时，建议使用测量得到的基准站已知坐标，而不是观测文件
中的近似坐标。

## 编译

使用 Visual Studio 打开 `solution1.vcxproj`，选择控制台应用程序并进行编译。
项目最初使用 Visual Studio `v142` 工具集创建。

程序源码中的中文注释保留了原始 GB2312 编码。若在其他编辑器或编译环境中
打开源码出现乱码，请将源文件编码设置为 GB2312，或使用支持该编码的编译
选项。README 文件使用 UTF-8 编码。

## 运行

建议从项目目录或能够正确解析 `data\sample\` 相对路径的工作目录运行生成的
`solution1.exe`。程序启动后依次输入：

1. 导航文件名和基准站观测文件名；
2. 基准站已知 ECEF 坐标 `apX apY apZ`；
3. 流动站观测文件名。

### 运行示例一

```text
请输入nav文件与基准站obs文件名：
data\sample\brdc0790.19n data\sample\hksl0790.19o
请输入基准站的已知坐标apX、apY、apZ：
-2393382.4160 5393861.1750 2412592.4110
请输入流动站obs文件名称：
data\sample\hkws0790.19o
```

### 运行示例二

```text
请输入nav文件与基准站obs文件名：
data\sample\brdc0640.18n data\sample\bor10640.18o
请输入基准站的已知坐标apX、apY、apZ：
3738358.5958 1148173.5785 5021815.7483
请输入流动站obs文件名称：
data\sample\wroc0640.18o
```

程序当前将结果输出到控制台，不会自动生成结果文件。输出内容包括定位
计算过程中的信息、流动站坐标以及相关定位结果。

## 注意事项

- 当前实现面向 RINEX 2 风格的导航文件和观测文件；
- 导航文件、基准站观测文件和流动站观测文件应属于同一观测日期；
- 文件路径按照程序运行时的工作目录解析；
- `Debug/`、`x64/`、`.obj`、`.pdb` 等 Visual Studio 编译产物不会提交；
- 本项目为本科毕业设计代码，主要用于学习、研究和算法复现。
