# Example data

The `sample` directory contains three RINEX files used together by the
pseudorange differential-positioning example:

- `brdc0790.19n`: broadcast navigation file for the 2019-03-20 set;
- `hksl0790.19o`: HKSL reference-station observations;
- `hkws0790.19o`: HKWS rover-station observations;
- `brdc0640.18n`: broadcast navigation file for the 2018-03-05 set;
- `bor10640.18o`: BOR1 reference-station observations;
- `wroc0640.18o`: WROC rover-station observations.

Use the three files from one set together. Do not mix the 2019-03-20 files
with the 2018-03-05 files. The data files are kept in their original RINEX
text form.
