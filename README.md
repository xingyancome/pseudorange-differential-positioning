# Pseudorange Differential Positioning

[中文说明](README.zh-CN.md)

This directory contains the main pseudorange differential positioning program
from the undergraduate graduation project.

## Program structure

- `solution1.cpp`: program entry point and the differential-positioning
  workflow. It processes the reference station first, generates pseudorange
  corrections, and then solves the rover-station position.
- `fileread.h` / `fileread.cpp`: RINEX 2 navigation and observation file
  reading, epoch matching, and differential-data preparation.
- `solution1.vcxproj`: Visual Studio project file for the console application.

The `solution1` program is the core of this project. The
`calculate_class_version` directory is a separate class-based single-point
positioning implementation and is not required by this program.

## Example data

The `data/sample` directory contains one complete same-day example:

| File | Role | Station |
| --- | --- | --- |
| `brdc0790.19n` | broadcast navigation file | GPS broadcast ephemeris |
| `hksl0790.19o` | reference-station observation file | HKSL |
| `hkws0790.19o` | rover-station observation file | HKWS |

The two observation files and the navigation file are from 2019-03-20. The
files are provided as small reproducible examples for this project; they are
not generated by the program.

It also contains a second, independent same-day set:

| File | Role | Station |
| --- | --- | --- |
| `brdc0640.18n` | broadcast navigation file | GPS broadcast ephemeris |
| `bor10640.18o` | reference-station observation file | BOR1 |
| `wroc0640.18o` | rover-station observation file | WROC |

This second set is from 2018-03-05. Do not mix files from the two sets.

## Running the example

Build the project first, then run the generated `solution1.exe` from the
directory containing the executable. When prompted, enter the following
values:

```text
请输入nav文件与基准站obs文件名：
data\sample\brdc0790.19n data\sample\hksl0790.19o
请输入基准站的已知坐标apX、apY、apZ：
-2393382.4160 5393861.1750 2412592.4110
请输入流动站obs文件名称：
data\sample\hkws0790.19o
```

The reference-station ECEF coordinates above are the approximate coordinates
recorded in the HKSL RINEX observation-file header. For a formal accuracy
evaluation, replace them with the surveyed reference-station coordinates.

To run the second set, use the BOR1 coordinates from its observation-file
header:

```text
请输入nav文件与基准站obs文件名：
data\sample\brdc0640.18n data\sample\bor10640.18o
请输入基准站的已知坐标apX、apY、apZ：
3738358.5958 1148173.5785 5021815.7483
请输入流动站obs文件名称：
data\sample\wroc0640.18o
```

The program first processes the reference station and calculates pseudorange
corrections. It then matches rover epochs, applies the corrections, and prints
the estimated rover coordinates and related positioning information. The
program currently prints results to the console; it does not write a result
file automatically.

The implementation expects RINEX 2-style navigation and observation files and
uses pseudorange observations from the input data. File names are entered
relative to the process working directory, so run the executable from the
project directory or adjust the paths accordingly.

## Build

Open `solution1.vcxproj` with Visual Studio and build the Console Application.
The project was originally created for the Visual Studio `v142` toolset.

The source files in this directory were copied without transcoding. Chinese
comments retain the original GB2312 encoding; configure the editor and compiler
to use the matching source encoding when needed.

This is an archived undergraduate graduation-project implementation. Large
RINEX observation files and Visual Studio build outputs are intentionally not
included in this directory.
